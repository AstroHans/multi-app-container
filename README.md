# Multi-App Container

Eine Web-Anwendung, die verschiedene Web-Apps in einem Container zusammenfasst.

## Deployment auf Netlify

1. Erstellen Sie ein neues Repository auf GitHub und laden Sie diese Dateien hoch
2. Gehen Sie zu [Netlify](https://www.netlify.com/) und melden Sie sich an
3. Klicken Sie auf "New site from Git"
4. Wählen Sie Ihr GitHub-Repository aus
5. Behalten Sie die Standardeinstellungen bei:
   - Build command: leer lassen
   - Publish directory: .
6. Klicken Sie auf "Deploy site"

## Funktionen

- Mehrere Web-Apps in einem Container
- Responsive Design
- Einfache Navigation
- Kompaktes Layout

## Technische Details

- Reine HTML/CSS/JavaScript-Implementierung
- Verwendet iframes für App-Integration
- Responsive Grid-Layout
- Optimiert für verschiedene Bildschirmgrößen

## Installation

1. Stellen Sie sicher, dass Node.js auf Ihrem System installiert ist
2. Klonen Sie dieses Repository
3. Öffnen Sie ein Terminal im Projektverzeichnis
4. Führen Sie folgende Befehle aus:

```bash
npm install
npm start
```

## Hinweise

- Einige Web-Apps erfordern möglicherweise eine Anmeldung
- Die Anwendung benötigt eine stabile Internetverbindung
- Die Größe des Fensters kann nach Bedarf angepasst werden
